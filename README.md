# Harbor

**A native macOS workspace for terminals, remote files, and desktop sessions.**

[简体中文](README.zh-CN.md) · [Project status](app/PROJECT-STATUS.md) · [Build verification](app/VERIFICATION.md)

Harbor brings local shells, SSH, SFTP, serial connections, RDP, VNC, and SSH tunnels into a Swift/AppKit application. It uses Ghostty for the main terminal experience, with a lightweight Legacy backend available as a fallback. A small Rust launcher builds and embeds the native executable.

This is an early development project. Local builds and selected workflows have been tested on Apple Silicon; it is not a complete replacement for MobaXterm, and compatibility with every server or device is not claimed. Harbor is not affiliated with MobaXterm or Mobatek.

## Features

- **Terminals:** local PTY shells, tabs, split panes, scrollback, search, configurable fonts, and shortcuts.
- **Connections:** SSH, jump hosts, folders, favorites, recent sessions, and explicit workspace save/restore.
- **Remote files:** SFTP browsing, upload/download, multi-selection, recursive transfers, and UTF-8 editing with conflict checks.
- **Remote desktops:** embedded RDP/VNC sessions, keyboard/mouse input, explicit text clipboard actions, and optional external-client handoff.
- **Device access:** configurable serial connections and local, remote, or SOCKS SSH tunnels.
- **Productivity:** command snippets, selected-session input broadcast, session logs, history export, and macro recording/playback.
- **Migration:** Harbor JSON, a supported subset of SSH config, and a supported subset of MobaXterm bookmarks. Password vaults are not imported.
- **Native interface:** English and Simplified Chinese; light, dark, and automatic system appearance.

See the [feature matrix and limitations](app/PROJECT-STATUS.md) for the implemented scope.

## Requirements

- macOS with Xcode Command Line Tools (`xcrun`, Swift, and Clang).
- Rust/Cargo and Python 3 available on `PATH`.
- A normal logged-in macOS desktop session for the application and UI tests. Use a native arm64 terminal on Apple Silicon, not a Rosetta shell.
- For the full app: **Zig 0.17.0**, CMake, pkg-config, and OpenSSL 3.

The full build scripts currently expect Homebrew OpenSSL at `/opt/homebrew/opt/openssl@3`. Apple Silicon is the validated target; the full Intel build path has not been validated. A minimum supported macOS release has not yet been established.

## Build from source

Run these commands from your clone's root directory. The Windows application is not a build input.

### Minimal Legacy terminal

```sh
cargo build --offline --release
./target/release/harbor-terminal
```

This route does not require the Ghostty or FreeRDP submodules. It does not package the Ghostty engine or embedded desktop helper; those features need the full build below. Installed compiler/toolchain requirements still apply to an offline build.

### Full Ghostty + embedded desktop application

Initialize the pinned dependencies:

```sh
bash scripts/fetch-dependencies.sh
python3 scripts/verify-ghostty.py
```

With the required tools already installed:

```sh
export ZIG="$(command -v zig)"
bash scripts/build-ghostty.sh
mkdir -p checks
bash app/package-ghostty.sh
python3 scripts/verify-bundle.py dist/Harbor.app
python3 scripts/verify-package-metadata.py dist/Harbor.app
open dist/Harbor.app
```

The result is `dist/Harbor.app`. The scripts do not install Zig; `ZIG` must point to version 0.17.0. The engine build may fetch upstream dependencies. Packaging builds the FreeRDP helper, copies its library dependencies, and collects third-party notices.

Ghostty is pinned to unmodified upstream **1.4.0**. `vendor/ghostty-build.json` is regenerated by the engine build and records local hashes, not a cross-machine byte-reproducibility guarantee.

## Language and appearance

- **Harbor → Language:** Follow System, English, or 简体中文. A language change is saved and applies on the next launch.
- **Harbor → Appearance:** Follow System, Light, or Dark. Changes apply immediately; system mode follows macOS appearance changes.
- New terminal profiles follow the interface appearance. Previously saved explicit terminal themes are preserved. Ghostty's **Terminal engine → Terminal preferences → Colors** includes **Follow Appearance** for new terminals.

Terminal output, user-defined names, paths, and protocol identifiers are not translated. See [localization](app/LOCALIZATION.md) and [appearance](app/APPEARANCE.md).

## Verification

```sh
./target/release/harbor-terminal --self-test
python3 scripts/check-localization.py
```

After building the full app, run the appearance checks from a macOS desktop session:

```sh
bash app/tests/appearance/build.sh
python3 app/tests/appearance/run.py
```

An earlier local build passed 33 appearance checks, a separate cross-process preference check, and 77 application self-checks. These historical results do not establish acceptance of the current notarized artifact: its corresponding unsigned build has unresolved self-test, appearance, and preference-persistence results that require verification in a normal desktop session. Details, artifact identities, and reproduction commands are in the [verification notes](app/VERIFICATION.md).

Generated apps, test logs and screenshots under `checks/` are ignored by Git and are not included. A complete local build of the public source with freshly fetched Ghostty/FreeRDP dependencies has passed; see [public-source build validation](app/PUBLIC-BUILD-VALIDATION.md). No GitHub CI result, Developer ID release, or cross-machine byte reproducibility is claimed.

## Limitations and data handling

- Embedded desktops do not provide audio, drive/device redirection, or desktop split-pane restoration. VNC authentication and encoding support is limited; see [embedded desktop support](app/P3-EMBEDDED-DESKTOP.md).
- There is no bundled X server. X11 workflows require an external installation such as XQuartz.
- File-transfer batches are not transactional. Partial uploads may remain after failure; remote editing cannot eliminate every race with another writer.
- Macro playback sends timed input; it does not detect when a command finishes.
- SSH authentication uses system OpenSSH. Harbor does not implement a password vault; desktop credentials are used for the connection. Saved sessions, explicit logs, exports, and macros can still contain sensitive information—review them before sharing.
- A Developer ID signed DMG has completed Apple notarization and ticket stapling, but has not been published. Functional acceptance remains open; see [artifact identity and outstanding checks](app/PUBLIC-BUILD-VALIDATION.md).

## Contributing

Before a large change, discuss its scope with the maintainer. Keep patches focused and include relevant build/test results. Do not include real credentials, private session exports, original proprietary binaries, or generated dependency/build directories.

For translations, edit `app/Resources/zh-Hans.json`, run `python3 scripts/generate-localization.py`, and include the generated catalog. Read the [application documentation](app/README.md) and [third-party credits](app/CREDITS.md) before changing integration code.
