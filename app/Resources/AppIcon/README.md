# Harbor app icon

Harbor.png is the 1254 × 1254 RGBA source artwork generated with the built-in image generation tool. The package workflow uses macOS sips and a standard-library ICNS encoder to produce Harbor.icns with 16, 32, 128, 256 and 512 point representations at 1× and 2×. No image-generation service is needed to build the application.

The bundled Info.plist declares CFBundleIconFile. Both the artwork and conversion script are included in build provenance.
